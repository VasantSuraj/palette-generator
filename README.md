# Palette Generator

A tiny web app that generates random color palettes.

## How to run

Double-click `index.html` to open it in your browser. No installs needed.

## How to use

- Press **Space** or click **Generate palette** for new colors
- Click a color to copy its hex code
- Click **Lock** to keep a color while generating new ones

## Practice ideas (make a change, then commit and push)

1. Change the title in `index.html`
2. Change `NUMBER_OF_COLORS` in `script.js` from 5 to 3
3. Change the button color in `style.css`
